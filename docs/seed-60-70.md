# Runbook: semilla de catálogo 60s/70s

**Feature**: `004-catalogo-60-70`  
**Contrato**: [contracts/seed-process.md](../specs/004-catalogo-60-70/contracts/seed-process.md)  
**Checklist editorial**: [contracts/editorial-review.md](../specs/004-catalogo-60-70/contracts/editorial-review.md)

## Invariante

Este proceso se ejecuta **solo en el host del mantenedor**. MUST NOT formar parte de
`kodi_plugin.run` ni de la navegación del oyente. MUST NOT rehostear ni descargar
ficheros de vídeo al repositorio.

## Pasos 1–6

| Paso | Qué hacer | Salida |
|------|-----------|--------|
| 1 Candidatos | Generar lista asistida (IA / listas históricas) de pop/rock/canción española 60/70 | `specs/004-catalogo-60-70/seed-work/candidates.md` (≥50 brutos recomendable) |
| 2 Ids | Resolver `video_id` públicos (manual o `yt-dlp`); desechar sin id usable | mismas filas con id de 11 chars |
| 3 Validación mecánica | Formato `Artista - Canción`, `VIDEO_ID_RE`, sin duplicados intra-año | `format_ok` en candidates |
| 4 Editorial | Aplicar E1–E6 (`seed-work/editorial-checklist.md`) | `editorial_ok`; `publish-list.md` |
| 5 Smoke | 5 ids 60s + 5 ids 70s vía Kodi u oEmbed (`resources/lib/youtube_probe.py` en host) | `validation-log.md` |
| 6 Publicar | Escribir solo años con ≥1 fila en `resources/csv/YYYY.csv`; README + versión | umbrales ≥40 filas, ≥8 años, ambas décadas |

## Conteos (SC-002)

```bash
python3 scripts/count_seed_60_70.py
```

Esperado: `years >= 8`, `rows >= 40`, `decade_60s True`, `decade_70s True`.

## Validación de catálogo (host)

```bash
python3 -m pip install -r requirements-dev.txt
PYTHONPATH=resources/lib python3 -m pytest -q \
  tests/unit/test_catalog_load.py \
  tests/unit/test_catalog_video_ids.py \
  tests/unit/test_catalog_years.py
```

`catalog.load_year` / `list_years` viven en `resources/lib/catalog.py` y se usan desde
tests; no importar este runbook ni `scripts/` desde `addon.py`.

PYTHONPATH=resources/lib python3 - <<'PY'

## Regeneración

Para ampliar la base: repetir pasos 1–6 sobre nuevos candidatos **sin borrar** los
CSV 1980–1999. Años sin filas aceptadas → no crear CSV vacío.

Opcional en host: `scripts/resolve_seed_ids.py` busca el primer resultado
YouTube con `yt-dlp` para una lista fija de títulos (solo mantenedor).
